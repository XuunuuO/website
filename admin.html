连接 GitHub 发布账号

授权码只在本次打开页面期间保存在内存，不会保存在网站、代码、草稿或浏览器存储中。

如何创建发布授权码
  1. 进入 GitHub 授权码页面 ↗
  2. Repository access 选择 Only select repositories → website。
  3. Repository permissions 中 Contents 选择 Read and write。
  4. 复制生成的 fine-grained token 到下方，切勿分享给别人。

版本记录与恢复

恢复只针对 data.js（作品与文本内容），通过新增提交完成；不会删除旧文件、撤销网站设计或删除媒体文件。恢复后无法直接找回未备份的本地草稿。
