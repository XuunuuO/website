首次连接：如何获取专用授权码
  1. 打开 GitHub 授权码设置 ↗，名称可填 Xu Nuo Studio。
  2. 设置到期时间，例如 30 天。
  3. Repository access 选择 Only select repositories，只选择 website。
  4. Repository permissions 中仅将 Contents 设为 Read and write；Metadata 保持默认只读。
  5. 生成后复制到下方。请勿把授权码发送给别人或写进作品内容。
